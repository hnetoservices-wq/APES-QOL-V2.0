# Security policy

APES QoL is a Chrome extension that interacts with Travian Kingdoms pages and stores account-related extension data locally. Please handle potentially sensitive findings carefully.

**Do not open a public Issue or Pull Request containing vulnerabilities, account credentials, auth cookies, tokens, private reports, personal data or reproduction steps that could be abused.**

If GitHub's **Security → Report a vulnerability** option is available for this repository, use it for private disclosure. Otherwise, contact the repository maintainer privately through an existing trusted channel and request a secure reporting method before sharing details.

Include a concise impact description, affected version/branch and a minimal sanitized reproduction. Do not test against other users' accounts without permission.

The maintainer will review reports and determine the appropriate remediation and disclosure timing. No automatic security-response deadline is promised.
